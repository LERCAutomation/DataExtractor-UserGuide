DataExtractor for MapInfo User Guide
===================================

User guide for [DataExtractor for MapInfo](https://github.com/LERCAutomation/DataExtractor-MapInfo), covering the release recorded in [conf.py](conf.py).

The guide includes a [quick start and worked example](quickstart/quickstart.rst), administrator guidance, downloadable XML configuration examples, operating instructions and a release change log. It is published in HTML and PDF on [Read the Docs](https://readthedocs.org/projects/dataextractor-userguide/).

A separate [ArcGIS Pro version](https://github.com/LERCAutomation/DataExtractor-ArcPro) and [user guide](https://github.com/LERCAutomation/DataExtractor-ArcPro-UserGuide) are available.
